문제 1) 어떤 수를 입력 받고, 1부터 입력받은 수의 범위 안에 있는 모든 소수를 출력하는 프로그램을 작성하시오.

 

문제 2) 어떤 정수 (입력)의 특정한 비트를 특정 값으로 설정하기 위한 프로그램을 작성하시오.

 

- 자료 입력

1) 어떤 정수 number를 입력받음

2) 0부터 31의 범위에 있는 정수 n를 입력 받음

3) 0, 또는 1을 입력받음

 

- 자료 처리

4) 1에서 입력받은 정수 number의 n번째 비트를 3에서 입력받은 수(0 또는 1)로 설정하여 결과값 result로 저장하기 위한 코드를 작성하시오.

 

-결과 출력

5)

  - 1에서 입력받은 수 number를 16진수와 2진수로 출력하시오.

  - 4의 결과로 산출된 값 result를 16진수와 2진수로 출력하시오.
